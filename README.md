# ReversiRetro

仕様書に基づく、ブラウザだけで動くオセロ局面手順解析MVPです。Rust、バックエンド、外部ライブラリは使用していません。盤面のルール処理と逆向きDFSは JavaScript の Web Worker で実行します。

## 起動

リポジトリのルートで次を実行し、表示されたURLをブラウザで開きます。

```text
node serve.js
```

外部パッケージは不要です。GitHub Pagesではリポジトリのルートを公開元にすると、ルートの `index.html` からアプリへ移動します。`file://` 直開きは Web Worker の制約で動かないブラウザがあるため、HTTP(S)で開いてください。

## 使い方

1. 盤面をクリック入力するか、`B`（黒）、`W`（白）、`.`（空）の8文字を8行で貼り付けます。
2. MVPの入力モードは終局盤面です。黒・白の双方に合法手がないことをリアルタイムに検証します。
3. 「手順を復元」を押すと、標準初期局面からの合法手順を逆向きDFSで探索します。
4. `FOUND` の結果はエンジン内でも棋譜を再生し、入力盤面と一致することを検証してから表示します。
5. 最初へ / 1手戻る / 再生 / 1手進む / 最後へ、棋譜行の選択、棋譜コピーで結果を確認できます。着手マスは金色、反転マスは青い破線で表示されます。

### ハイブリッド探索

全探索だけでは到達までの組合せ爆発が大きいため、エンジンは探索前に小さな「検証済み棋譜帳」を照合します。現在は、標準初期配置から合法手を通常の `legal` / `apply` で進め、手番側に合法手がないときだけパスを挿入して構築した、全白終局と全黒終局の2例を収録しています。各棋譜は登録時と検索時に `replay` で再生し、入力盤面との完全一致を確認します。該当すれば予算がゼロでも `FOUND`（探索方式: `VERIFIED_BOOK`、探索ノード: 0）を返し、それ以外の局面は従来の対称性付き逆向きDFS（探索方式: `REVERSE_DFS`）へ進みます。

棋譜帳の着想と対象例の出典は [othello の記事](https://www.ptt.cc/bbs/othello/M.1646832634.A.661.html) です。棋譜帳の手順は元記事の実戦棋譜を特定するものではなく、入力盤面へ到達する合法な証人列です。また、実行時の `replay` 検証に成功した場合のみ結果として表示するため、ルール実装を変更した場合は検証結果も変わります。

### 探索モード

- `クイック`: 最大5万ノードまたは3秒。入力確認向けです。
- `じっくり`: 最大500万ノードまたは5分。
- `無制限`: 時間・ノード数で停止せず、解の発見、完全探索、または「停止」を押すまで継続します。

無制限モードは局面によって数時間以上かかり、CPUを継続的に使用します。探索中はブラウザのタブを開いたままにしてください。失敗状態キャッシュは50万件に制限し、古い項目を退避してメモリ使用量を抑えます。キャッシュの退避は再探索を増やすだけで、合法な経路を除外したり、未完了の探索を `UNREACHABLE_PROVEN` に変えたりはしません。

探索結果は以下を区別します。

- `FOUND`: 検証済みの合法手順を発見
- `UNREACHABLE_PROVEN`: 探索を完了し、到達経路がないと証明
- `UNKNOWN_TIMEOUT`: 時間またはノード上限に到達（到達不能とは限らない）
- `INVALID_INPUT`: 盤面または終局条件が不正
- `CANCELLED`: ユーザーが停止

## テスト

```text
npm test
```

npmが利用できない環境では、同じ内容を次で実行できます。

```text
node --test
node --check engine.js
node --check public/app.js
node --check public/worker.js
```

テストには通常の合法手・複数方向反転・不正着手、逆向き predecessor property、内部アンカーを持つ連続石、パス、短いランダム相当局面の復元、リプレイ一致、終局入力検証、タイムアウト・キャンセルを含みます。
