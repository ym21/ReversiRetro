# ReversiRetro

仕様書に基づく、ブラウザだけで動くオセロ局面手順解析MVPです。Rust、バックエンド、外部ライブラリは使用していません。盤面のルール処理、目標指向の前向き探索、逆向きDFSは JavaScript の Web Worker で実行します。

## 起動

リポジトリのルートで次を実行し、表示されたURLをブラウザで開きます。

```text
node serve.js
```

外部パッケージは不要です。GitHub Pagesではリポジトリのルートを公開元にすると、ルートの `index.html` からアプリへ移動します。`file://` 直開きは Web Worker の制約で動かないブラウザがあるため、HTTP(S)で開いてください。

## 使い方

1. 盤面をクリック入力するか、`B`（黒）、`W`（白）、`.`（空）の8文字を8行で貼り付けます。
2. MVPの入力モードは終局盤面です。黒・白の双方に合法手がないことをリアルタイムに検証します。
3. 「手順を復元」を押すと、標準初期局面（黒番）からの合法手順を探索します。
4. `FOUND` の結果はエンジン内でも棋譜を再生し、入力盤面と一致することを検証してから表示します。
5. 最初へ / 1手戻る / 再生 / 1手進む / 最後へ、棋譜行の選択、棋譜コピーで結果を確認できます。着手マスは金色、反転マスは青い破線で表示されます。

### 探索方法

まず `TARGET_FORWARD` で、標準初期局面から黒番で合法手を順に生成します。現在盤面にある石が目標盤面の空きマスに入った枝、目標と異なる色の角を占めた枝、角から連続する確実な安定辺石の色が異なる枝は、石が除去できない／安定石が反転できないため即座に破棄します。各合法手は目標色との一致数の増減、目標色で確保した角、将来の合法手数を使って順序付けしますが、これは順番を決めるだけで、合法な枝そのものは省略しません。パスも通常ルールで処理します。

探索で見つけた手順は `replay` で再生し、入力盤面との完全一致を検証してから表示します。前向き探索が上限に達した場合は、対称性付きの `REVERSE_DFS` に切り替えます。`target.sideToMove` を指定した場合は目標局面の次の手番として解釈し、探索開始手番は常に標準ルールの黒です。探索方式は `TARGET_FORWARD` または `REVERSE_DFS` として表示されます。

### 探索モード

- `クイック`: 最大5万ノードまたは3秒。入力確認向けです。
- `じっくり`: 最大500万ノードまたは5分。
- `無制限`: 時間・ノード数で停止せず、解の発見、完全探索、または「停止」を押すまで継続します。

無制限モードは局面によって数時間以上かかり、CPUを継続的に使用します。探索中はブラウザのタブを開いたままにしてください。失敗状態キャッシュは50万件に制限し、古い項目を退避してメモリ使用量を抑えます。キャッシュの退避は再探索を増やすだけで、合法な経路を除外したり、未完了の探索を `UNREACHABLE_PROVEN` に変えたりはしません。

探索結果は以下を区別します。

- `FOUND`: 検証済みの合法手順を発見
- `UNREACHABLE_PROVEN`: 探索を完了し、到達経路がないと証明
- `UNKNOWN_TIMEOUT`: 時間またはノード上限に到達（到達不能とは限らない）
- `INVALID_INPUT`: 盤面または終局条件が不正
- `CANCELLED`: ユーザーが停止

## テスト

```text
npm test
```

npmが利用できない環境では、同じ内容を次で実行できます。

```text
node --test
node --check engine.js
node --check public/app.js
node --check public/worker.js
```

テストには通常の合法手・複数方向反転・不正着手、逆向き predecessor property、内部アンカーを持つ連続石、パス、全白盤面の計算による復元、角色・安定辺石・目標空きマスの枝刈り、リプレイ一致、終局入力検証、タイムアウト・キャンセルを含みます。
